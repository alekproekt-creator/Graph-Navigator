Описание программы

Graph Navigator — консольное приложение для работы с графами.
Позволяет создавать ориентированные/неориентированные/взвешенные графы, добавлять и удалять вершины и рёбра, выполнять обходы (BFS/DFS), искать кратчайшие пути (Dijkstra для взвешенных, BFS для невзвешенных), сохранять/загружать граф в JSON. Решает задачу быстрой навигации и анализа структур связей.

Требования для запуска

- Python 3.10 или выше
- Библиотеки: стандартная библиотека Python (json, heapq, collections). Дополнительные пакеты не требуются.

Структура проекта

- graph_navigator.py — основная программа (OO, фабрика, алгоритмы, консоль).
- test_graph.json — пример сохранённого графа (опционально).
- README.md — этот файл.

Как запустить


git clone https://github.com/alekproekt-creator/Graph-Navigator
cd graph-navigator
python graph_navigator.py
# или запустить встроенные тесты
python graph_navigator.py test


Как пользоваться (REPL)

При запуске откроется консоль с приглашением >>. Команды:

- add_node  — добавить вершину
- remove_node  — удалить вершину
- add_edge   [w] — добавить ребро (взвешенное, w по умолчанию 1.0)
- remove_edge   — удалить ребро
- bfs  — обход в ширину
- dfs  — обход в глубину
- sp_unweighted   — кратчайший путь (невзвешенный, BFS)
- sp_weighted   — кратчайший путь (взвешенный, Dijkstra)
- save  — сохранить граф в JSON
- load  — загрузить граф из JSON
- show — показать вершины и рёбра
- help — показать подсказку
- exit — выйти

Пример:

1. add_node A
2. add_node B
3. add_edge A B 2.5
4. show
5. sp_weighted A B
6. save mygraph.json

Валидация и ошибки

- Вершины должны иметь уникальные ключи. При дубликате — ошибка VertexExistsError.
- Рёбра можно добавлять только между существующими вершинами.
- Вес должен быть числом ≥ 0. Иначе — WeightError.
- Некорректные команды и отсутствующие вершины/рёбра — соответствующие исключения с сообщением.

Тестирование

Встроенные тесты запускаются командой:


python graph_navigator.py test

Тесты покрывают:

- Добавление/удаление вершин и рёбер.
- BFS/DFS.
- Кратчайшие пути для невзвешенных и взвешенных графов.
- Сериализация/десериализация в JSON.
- Краевые случаи: отсутствующие вершины, недопустимые веса, несвязные графы.
